# go-pdf v0.5.1

发布日期：2026-10-25

这是 v0.5.0 之后的补充版本，新增可选纯 Go CCITT Group 3 2-D 解码，并修正文本位置和发布质量边界。

## 新增

- `extension/g32d`：纯 Go CCITT Group 3 2-D provider，显式注册后启用。
- 支持 Group 3 2-D、混合 1-D/2-D 行、EOL tag、Pass/Horizontal/Vertical 模式。
- 支持 Columns/Rows、EncodedByteAlign、BlackIsZero、ImageMask。
- 增加 G3 2-D Poppler 参考对比、synthetic 回归、fuzz 和基准。

## 变更

- `displaylist.Version` 从 2.0 Minor bump 到 2.1。
- `displaylist.ImageInfo` / `extension.ImageConfig` 新增 CCITT 参数字段，均为 add-only。
- G3 2-D 在能力表中标记为 external；未注册 provider 时仍返回 Unsupported。
- 使用 `golang.org/x/image/ccitt` 的位读取/run 表/2-D 模式实现作为 BSD 适配基础，详见 `THIRD_PARTY.md`。

## 修复

- 修正 CTM 缩放文本的字号、字宽和词框上下界。
- 英文位置抽样词框边缘误差 P95 为 0.012 pt。
- 保持全量语料 0 render_error。

## 兼容性

- Core 默认行为不变，不新增第三方依赖。
- 使用 G3 2-D 需要显式注册 `extension/g32d`。
- `displaylist` 仍只保证增字段的 Minor 兼容，不保证 1.0 契约。
- Preview 仍不是打印级或 Adobe/Poppler 像素级替代品。
