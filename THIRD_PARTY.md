# Third-Party Notices

go-pdf is licensed under Apache-2.0. This file records third-party code,
embedded resources, and corpus data. Add an entry before merging anything that
is not covered by the Go standard library.

## Dependencies

G0 has no external Go module dependencies. The policy allows only
`golang.org/x/*`; any addition requires an ADR and a license review.

| Name | Version | License | Usage | Source |
| --- | --- | --- | --- | --- |
| Go standard library | toolchain | BSD-3-Clause | Runtime and tests | https://go.dev/ |

## Embedded resources

None in G0. Future CMap tables, standard-14 font metrics, and glyph lists must
record their source, version, and redistribution terms here before merge.

## Corpus and test data

Synthetic PDFs generated by `internal/testkit` are original works of this
project. Real-world corpus files are tracked in `testdata/manifest.csv` with
source and license fields; confidential customer files must not be committed.
