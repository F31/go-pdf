embedded resources, and corpus data. Add an entry before merging anything that

## Dependencies

The module allows only `golang.org/x/*`; any addition requires an ADR and a
license review. Current dependencies are listed below.

| Name | Version | License | Usage | Source |
| --- | --- | --- | --- | --- |
| Go standard library | toolchain | BSD-3-Clause | Runtime and tests | https://go.dev/ |
| `golang.org/x/image` | v0.39.0 | BSD-3-Clause | `font/sfnt` metrics and glyph advances | https://pkg.go.dev/golang.org/x/image |
| `golang.org/x/text` | v0.36.0 | BSD-3-Clause | Transitive dependency of `x/image/font/sfnt` | https://pkg.go.dev/golang.org/x/text |

## Embedded resources

| Name | Version | License | Usage | Source |
| --- | --- | --- | --- | --- |
| Liberation font metrics | 2.x (system package) | SIL Open Font License 1.1 | Provisional standard-14 width tables in `internal/font/base14_widths.go` | Generated by `scripts/gen_base14_widths.py` from Liberation Sans/Serif/Mono |
| Adobe CMap data (GB1/CNS1/Japan1/Korea1) | poppler-data 0.4.12-1 | Adobe CMap redistribution license (BSD-style) | Predefined Chinese, Japanese, and Korean CMaps in `internal/font/data/cmap.bin` | Generated by `scripts/gen_cmaps.py` from Adobe CMap resources; notice in `internal/font/data/CMAP-LICENSE.txt` |
| GoPDFTestSans test font | subset of Liberation Sans 2.x | SIL Open Font License 1.1 | SFNT metric test fixture in `testdata/fonts/gopdf-test-sans.ttf` | Renamed, character-subsetted Liberation Sans; notice in `testdata/fonts/LICENSE-gopdf-test-sans.txt` |

The generated base-14 tables contain numeric advance widths only. The CMap
binary contains mapping ranges only. The only redistributed font program is the
small test fixture in `testdata/fonts/`, used only by tests. The authoritative
Adobe base-14 AFM metrics should replace the provisional Liberation-derived
values after license review and corpus calibration. Future glyph lists and other
embedded resources must record their source, version, and redistribution terms
here before merge.

## Corpus and test data

Synthetic PDFs generated by `internal/testkit` are original works of this
project. Real-world corpus files are tracked in `testdata/manifest.csv` with
source and license fields; confidential customer files must not be committed.
