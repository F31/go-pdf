# ADR-0004: Raise the minimum Go version to 1.25

- Status: accepted
- Date: 2026-10-21
- Supersedes: ADR-0001 minimum toolchain version

## Decision

Raise the minimum supported Go version from 1.23 to 1.25 and test CI against
Go 1.25.x and 1.26.x.

## Rationale

`golang.org/x/image` v0.39.0 is the first release that fixes GO-2026-4962
(excessive memory allocation while parsing a malicious SFNT). That release
requires Go 1.25. Keeping the previous x/image release would leave a known
vulnerability reachable through `sfnt.Parse` on untrusted PDF font programs.

## Consequences

- `go.mod` declares `go 1.25.0`.
- CI runs the minimum Go 1.25 line and the current stable line.
- Developers on older toolchains rely on Go's automatic toolchain switching or
  must install Go 1.25+.
- ADR-0001 remains historical; its module path and repository decisions still
  apply.
